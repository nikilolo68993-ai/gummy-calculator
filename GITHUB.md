# Собрать Gummy через GitHub

GitHub Actions собирает калькулятор на Windows-сервере. На своём компьютере
не нужно устанавливать Flutter, Git или Visual Studio, если загружать код через сайт.

Сборка настроена в `.github/workflows/build-windows.yml`.
Она запускается по кнопке **Run workflow**, а также после изменения кода
в ветке `main` или `master`. Используется Flutter 3.47.5, на котором проверен проект.

## Первый раз через сайт GitHub

1. Создай репозиторий: https://github.com/new . Например, `gummy-calculator`.
   Можно выбрать Public или Private. Включи **Add a README file**, затем
   нажми **Create repository**.
2. Распакуй `Gummy-GitHub.zip`. Открой внутреннюю папку `gummy_calculator`.
3. В репозитории нажми **Add file → Upload files**. Перетащи содержимое папки
   проекта: `lib`, `assets`, `windows`, `linux`, `macos`, `web`, `test`, `docs`,
   а также файлы `pubspec.yaml`, `pubspec.lock`, `analysis_options.yaml`,
   `LICENSE` и `README.md`. Подтверди **Commit changes**.
   В корне репозитория должен появиться `pubspec.yaml`. Сам ZIP загружать не нужно.
4. Создай workflow отдельным файлом, чтобы он точно попал в нужную папку:
   **Add file → Create new file**. В поле имени введи
   `.github/workflows/build-windows.yml`. Вставь полное содержимое одноимённого
   YAML-файла из архива и нажми **Commit changes**.
5. Открой **Actions → Build Windows**. Если сборка уже запустилась автоматически,
   открой её. Если нет, нажми **Run workflow → Run workflow**.
6. После зелёной галочки открой завершённый запуск. Внизу, в **Artifacts**,
   нажми **Gummy-Windows-x64**. Для скачивания нужно быть авторизованным на GitHub.
7. Полностью распакуй скачанный архив и запусти **gummy_calculator.exe**.
   Все DLL и папка `data` должны остаться рядом. В этой сборке также будут
   библиотеки Visual C++, поэтому отдельно устанавливать инструменты сборки не нужно.

## Если проект уже загружен

Добавь `.github/workflows/build-windows.yml` в корень репозитория и открой Actions.
Workflow также умеет находить проект во вложенной папке `gummy_calculator`,
но сам файл workflow всегда должен быть в корневой `.github/workflows/`.

Если ты пользуешься GitHub Desktop или обычным Git, можно сразу закоммитить
всё содержимое проекта, включая `.github`. Отдельное создание YAML через сайт
тогда не требуется.

## Что делает сборка

Устанавливает Flutter на сервере, получает зависимости из зафиксированного
`pubspec.lock`, проверяет код и тесты, собирает Windows Release и упаковывает
полный комплект для запуска. В архив также копируются лицензия проекта,
лицензия шрифта и библиотеки Visual C++ из установленной на сервере Visual Studio.

Секреты и личные токены в настройках репозитория для этой сборки не требуются.
Готовый артефакт хранится 14 дней; после скачивания архив можно сохранить у себя.

## Если появилась красная галочка

Открой запуск, выбери **Build portable Windows app**, затем раскрой красный шаг.
Скопируй сообщение об ошибке или пришли ссылку на запуск — по нему можно понять,
какой шаг нужно исправить. Workflow пока подготовлен и проверен локально;
первую нативную Windows-сборку нужно запустить в твоём репозитории.
